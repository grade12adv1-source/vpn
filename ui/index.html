Checking system tools…

Clear boundaries

Aero manages your own server profiles. It does not provide VPN servers, a kill switch, or automatic reconnection. Your profile controls DNS and IPv4 / IPv6 coverage. Closing the app can leave the system tunnel running.

YOUR FIRST CONNECTION

Three steps to take off.

Aero is the client. Your server supplies the route.

01

Install WireGuard

On Windows, install the official WireGuard client. Aero uses its system service to create and remove tunnels.

02

Get a server profile

Export a client .conf from your WireGuard server or a provider that supports WireGuard configuration downloads. Each device needs its own private key.

A working server is required
03

Import & connect

Import your profile, check latency, and connect. Windows will request administrator approval for the tunnel service.

What does “tunnel active” mean?

The system has started your WireGuard interface or service. It does not confirm a successful peer handshake or Internet reachability. Check the official WireGuard client for handshake status; test a site after connecting.

For a lower-latency connection

Choose a server near you, compare endpoint latency while disconnected, and keep the server’s recommended MTU. Congestion, distance, and server load still determine real performance.

Remove this profile?

This removes its local configuration and private key. It won’t delete the peer on your server.
